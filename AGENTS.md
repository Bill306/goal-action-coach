# Agent Instructions

1. Keep `SKILL.md` concise and execution-oriented; move detailed wording, schemas, and examples into `references/` or `examples/`.
2. Preserve the core discipline: one question at a time, no list-style multi-questioning, echo the half-finished state after each question.
3. Keep result points numeric/pictorial and deadlines in `X月X日X点前` form.
4. Never skip a confirmation gate (goal → decomposition → final checklist).
5. Do not add extraneous files (CHANGELOG, INSTALLATION_GUIDE, etc.) to the repo.
6. Run `scripts/validate.sh` before committing or publishing changes.
